## 0. One-time Setup

### 0.1 Naya Web Project (Servlet / JSP / EJB ke liye)
1. `File → New Project → Java Web → Web Application → Next`
2. **Project Name** likho (har question me diya hai) → `Next`
3. **Server:** `GlassFish Server 4.0`, **Java EE Version:** `Java EE 7 Web` → `Finish`

### 0.2 Servlet kaise banaye
1. Projects tab → `Source Packages` pe right-click → `New → Servlet`
2. **Class Name** likho, **Package** = `p1` → `Next`
3. **"Add information to deployment descriptor (web.xml)" ko UNCHECK karo** → `Finish`
4. Pura generated code delete karo aur meri code paste karo (`@WebServlet` annotation se URL ban jata hai, web.xml nahi chahiye)

### 0.3 HTML / JSP file kaise banaye
`Web Pages` pe right-click → `New → HTML` (ya `JSP`) → File Name likho → `Finish`.
Naye project me `index.html` pehle se hota hai, usko edit karo (delete mat karo).

### 0.4 Run kaise kare
- Servlet: file pe right-click → `Run File` (Shift+F6). Agar "Set Servlet Execution URI" pooche to servlet ka URL (jaise `/CalcServlet`) likho.
- HTML/JSP: file pe right-click → `Run File`.
- URL format: `http://localhost:8080/<ProjectName>/<URLpattern>`

### 0.7 Exact steps and file paths for each practical

Follow these steps for each practical section below. The **Project** and **File** lines under each question give the exact project/file names for that practical.

   - Path: `File → New Project → Java Web → Web Application → Next`
   - Enter the project name shown under the question → `Next`.

2. **Create the package**
   - Path: `Projects → <Your Project> → Source Packages`
   - Right-click `Source Packages → New → Java Package` → package name: `p1` → `Finish`.
3. **Create each Servlet file**
   - Path: `Source Packages → p1`

   - If the wizard asks about `web.xml`, leave **Add information to deployment descriptor (web.xml)** unchecked when the code uses `@WebServlet` → `Finish`.

4. **Create each HTML/JSP page**
   - Path: `Web Pages`
   - Right-click `Web Pages → New → HTML` or `New → JSP`; enter the exact filename shown in the question's file list → `Finish`.
   - Paste the matching page code and save. If `index.html` already exists, edit it rather than creating a duplicate.

   - Start MySQL in XAMPP, run the database/table SQL in section 0.5 using phpMyAdmin, and add `MySQL JDBC Driver` through `Project → Libraries → Add Library`.
7. **For multi-file practicals**
   - Create every listed file at its specified path before running the HTML/JSP starting page.

### Q1-### Q1-1 & Q1-13. Create a simple calculator application using a Servlet. (Q1-13: Create a Servlet application that accepts two numbers and an arithmetic operation from an HTML form, calculates the result and displays it.)
**Project:** `CalcApp`  |  **File:** `Source Packages → p1 → CalcServlet.java`

**Steps and paths:**
1. Create the project using `File → New Project → Java Web → Web Application`; use the project name shown above, select GlassFish Server 4.0 / Java EE 7 Web, then click `Finish`.
2. Under `Source Packages`, create package `p1` if it does not exist: `Right-click Source Packages → New → Java Package → p1`.
3. Create the Java file at the exact path shown above (`Source Packages → p1 → <ClassName>.java`), paste the code below, and save.
4. Right-click the Servlet file → `Run File`; if asked for a Servlet execution URI, enter the URL pattern from its `@WebServlet` annotation.


```java
package p1;
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet("/CalcServlet")
public class CalcServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        res.getWriter().println("<form method='post'>No1: <input name='a'><br>No2: <input name='b'><br>"
            + "Operation: <select name='op'><option>+</option><option>-</option><option>*</option>"
            + "<option>/</option><option>%</option></select><br><input type='submit' value='Calculate'></form>");
    }
    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        double a = Double.parseDouble(req.getParameter("a"));
        double b = Double.parseDouble(req.getParameter("b"));
        String op = req.getParameter("op");
        double r = 0;
        if (op.equals("+")) r = a + b;
        else if (op.equals("-")) r = a - b;
        else if (op.equals("*")) r = a * b;
        else if (op.equals("/")) r = a / b;
        else r = a % b;
        res.setContentType("text/html");
        res.getWriter().println("<h3>Result: " + a + " " + op + " " + b + " = " + r + "</h3>");
    }
}
```
**URL:** `http://localhost:8080/CalcApp/CalcServlet`

**Output:**
```
No1: [10]  No2: [5]  Operation: [+]  [Calculate]
        ↓
Result: 10.0 + 5.0 = 15.0
```

### Q1-### Q1-2. Develop a basic calculator using ServletInputStream and ServletOutputStream to perform addition, subtraction, multiplication, division and modulus.
**Project:** `StreamCalc`  |  **File:** `Source Packages → p1 → StreamCalcServlet.java`

**Steps and paths:**
1. Create the project using `File → New Project → Java Web → Web Application`; use the project name shown above, select GlassFish Server 4.0 / Java EE 7 Web, then click `Finish`.
2. Under `Source Packages`, create package `p1` if it does not exist: `Right-click Source Packages → New → Java Package → p1`.
3. Create the Java file at the exact path shown above (`Source Packages → p1 → <ClassName>.java`), paste the code below, and save.
4. Right-click the Servlet file → `Run File`; if asked for a Servlet execution URI, enter the URL pattern from its `@WebServlet` annotation.


```java
package p1;
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet("/StreamCalcServlet")
public class StreamCalcServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        res.getWriter().println("<form method='post'>A: <input name='a'> B: <input name='b'> "
            + "<select name='op'><option value='add'>Addition</option><option value='sub'>Subtraction</option>"
            + "<option value='mul'>Multiplication</option><option value='div'>Division</option>"
            + "<option value='mod'>Modulus</option></select> <input type='submit'></form>");
    }
    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        ServletInputStream in = req.getInputStream();
        byte[] buf = new byte[1024];
        int n = in.read(buf);
        String body = new String(buf, 0, n);               // example: a=10&b=5&op=add
        String[] p = body.split("&");
        double a = Double.parseDouble(p[0].split("=")[1]);
        double b = Double.parseDouble(p[1].split("=")[1]);
        String op = p[2].split("=")[1];
        double r = 0;
        if (op.equals("add")) r = a + b;
        else if (op.equals("sub")) r = a - b;
        else if (op.equals("mul")) r = a * b;
        else if (op.equals("div")) r = a / b;
        else r = a % b;
        res.setContentType("text/html");
        ServletOutputStream out = res.getOutputStream();
        out.println("<h3>" + op + " of " + a + " and " + b + " = " + r + "</h3>");
    }
}
```
**URL:** `http://localhost:8080/StreamCalc/StreamCalcServlet`

**Output:**
```
A: [20]  B: [6]  [Modulus]  [Submit]
        ↓
mod of 20.0 and 6.0 = 2.0
```

### Q1-### Q1-5. Create a registration Servlet using JDBC to accept username, password, email and country from an HTML form and store the details in a database.
**Project:** `RegisterApp`  |  **Needs:** MySQL + `users` table (Setup 0.5)

**Steps and paths:**
1. Create the project using `File → New Project → Java Web → Web Application`; use the project name shown above, select GlassFish Server 4.0 / Java EE 7 Web, then click `Finish`.
2. Under `Source Packages`, create package `p1` if it does not exist: `Right-click Source Packages → New → Java Package → p1`.

**File:** `Source Packages → p1 → RegisterServlet.java`

```java
package p1;
import java.io.*;
import java.sql.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet("/RegisterServlet")
public class RegisterServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        res.getWriter().println("<h3>Registration</h3><form method='post'>"
            + "Username: <input name='username'><br>Password: <input type='password' name='password'><br>"
            + "Email: <input name='email'><br>Country: <select name='country'><option>India</option>"
            + "<option>USA</option><option>UK</option></select><br><input type='submit' value='Register'></form>");
    }
    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/exam", "root", "");
            PreparedStatement ps = con.prepareStatement("insert into users values(?,?,?,?)");
            ps.setString(1, req.getParameter("username"));
            ps.setString(2, req.getParameter("password"));
            ps.setString(3, req.getParameter("email"));
            ps.setString(4, req.getParameter("country"));
            int i = ps.executeUpdate();
            out.println(i > 0 ? "<h3>Registration successful</h3>" : "<h3>Registration failed</h3>");
            con.close();
        } catch (Exception e) {
            out.println(e);
        }
    }
}
```
**URL:** `http://localhost:8080/RegisterApp/RegisterServlet`

**Output:**
```
Registration successful
(phpMyAdmin → exam → users me nayi row dikhegi)
```

```java
package p1;
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet("/FileServlet")
@MultipartConfig
public class FileServlet extends HttpServlet {
    String dir = "C:/uploads";

    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        String f = req.getParameter("file");
        if (f != null) {                                         // DOWNLOAD
            res.setContentType("application/octet-stream");
            res.setHeader("Content-Disposition", "attachment; filename=\"" + f + "\"");
            FileInputStream in = new FileInputStream(new File(dir, f));
            OutputStream os = res.getOutputStream();
            byte[] b = new byte[1024];
            int n;
            while ((n = in.read(b)) != -1) os.write(b, 0, n);
            in.close();
            return;
        }
        res.setContentType("text/html");                         // UPLOAD form + file list
        PrintWriter out = res.getWriter();
        out.println("<h3>Upload File</h3><form method='post' enctype='multipart/form-data'>"
            + "<input type='file' name='file'> <input type='submit' value='Upload'></form><h3>Download Files</h3>");
        File[] list = new File(dir).listFiles();
        if (list != null)
            for (File x : list)
                out.println("<a href='FileServlet?file=" + x.getName() + "'>" + x.getName() + "</a><br>");
    }

    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        Part p = req.getPart("file");
        new File(dir).mkdirs();
        p.write(dir + "/" + p.getSubmittedFileName());
        res.sendRedirect("FileServlet");
    }
}
```

### Q1-### Q1-10. Create a Servlet application demonstrating non-blocking read operations.
**Project:** `NonBlockApp`  |  **File:** `p1 → NonBlockServlet.java`

**Steps and paths:**
1. Create the project using `File → New Project → Java Web → Web Application`; use the project name shown above, select GlassFish Server 4.0 / Java EE 7 Web, then click `Finish`.
2. Under `Source Packages`, create package `p1` if it does not exist: `Right-click Source Packages → New → Java Package → p1`.

```java
package p1;
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet(urlPatterns = "/NonBlockServlet", asyncSupported = true)
public class NonBlockServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        res.getWriter().println("<form method='post'>Message: <input name='msg'> <input type='submit'></form>");
    }
    protected void doPost(HttpServletRequest req, final HttpServletResponse res) throws ServletException, IOException {
        final AsyncContext ac = req.startAsync();
        final ServletInputStream in = req.getInputStream();
        in.setReadListener(new ReadListener() {
            StringBuilder sb = new StringBuilder();
            public void onDataAvailable() throws IOException {
                byte[] b = new byte[1024];
                while (in.isReady() && !in.isFinished()) {
                    int n = in.read(b);
                    if (n > 0) sb.append(new String(b, 0, n));
                }
            }
            public void onAllDataRead() throws IOException {
                res.setContentType("text/html");
                res.getWriter().println("<h3>Data received (non-blocking read): " + sb + "</h3>");
                ac.complete();
            }
            public void onError(Throwable t) { ac.complete(); }
        });
    }
}
```

```

        ↓
```

```java
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        out.println("<h2>Quiz</h2><form method='post'>");
        for (int i = 0; i < q.length; i++) {
            out.println("<b>Q" + (i + 1) + ". " + q[i] + "</b><br>");
            for (int j = 0; j < 4; j++)
                out.println("<input type='radio' name='q" + i + "' value='" + j + "'>" + o[i][j] + "<br>");
            out.println("<br>");
        }
        out.println("<input type='submit' value='Submit Quiz'></form>");
    }
    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        int correct = 0;
        for (int i = 0; i < q.length; i++) {
            String v = req.getParameter("q" + i);
            if (v != null && Integer.parseInt(v) == ans[i]) correct++;
```

**Steps and paths:**

2. Under `Source Packages`, create package `p1` if it does not exist: `Right-click Source Packages → New → Java Package → p1`.
3. Create the Java file at the exact path shown above (`Source Packages → p1 → <ClassName>.java`), paste the code below, and save.
4. Right-click the Servlet file → `Run File`; if asked for a Servlet execution URI, enter the URL pattern from its `@WebServlet` annotation.


```java
package p1;
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet("/ValidateServlet")
public class ValidateServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        res.getWriter().println("<form method='post'>Name: <input name='name'><br>Age: <input name='age'><br>"
            + "Email: <input name='email'><br><input type='submit'></form>");
    }
    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        String name = req.getParameter("name"), email = req.getParameter("email");
        String err = "";
        if (name == null || name.trim().equals("")) err += "Name is required<br>";
        try {
            int age = Integer.parseInt(req.getParameter("age"));
            if (age < 1 || age > 100) err += "Age must be between 1 and 100<br>";
        } catch (Exception e) { err += "Age must be a number<br>"; }
        if (email == null || !email.contains("@")) err += "Email is invalid<br>";
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        if (err.equals("")) out.println("<h3>All inputs are valid. Welcome " + name + "!</h3>");
        else out.println("<font color='red'>" + err + "</font><a href='ValidateServlet'>Back</a>");
    }
}
```
**URL:** `http://localhost:8080/ValidateApp/ValidateServlet`

**Output:**
```
Name="", Age=abc, Email=xyz  →  Name is required / Age must be a number / Email is invalid
Ravi, 21, ravi@gmail.com     →  All inputs are valid. Welcome Ravi!
```

4. Right-click the Servlet file → `Run File`; if asked for a Servlet execution URI, enter the URL pattern from its `@WebServlet` annotation.


```java
package p1;
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;

@WebServlet("/WaterBillServlet")
public class WaterBillServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {
        res.setContentType("text/html");
        res.getWriter().println("<h3>Water Bill</h3><form method='post'>Units consumed: <input name='units'> <input type='submit'></form>");
    }
    protected void doPost(HttpServletRequest req, HttpServletResponse res) throws ServletException, IOException {

        double bill;

        else bill = 500 + 700 + (u - 200) * 10;
```
